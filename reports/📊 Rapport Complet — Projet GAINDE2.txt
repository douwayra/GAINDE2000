1. 🎯 Contexte et Objectif du Projet
GAINDE 2000 administre le système ORBUS, le guichet unique de télédéclaration douanière du Sénégal. Ce système enregistre tous les flux d'importation, d'exportation, de réexportation et de transit de marchandises.

L'objectif de la mission était de construire, de bout en bout, une plateforme analytique sécurisée capable de :

Ingérer, nettoyer et centraliser des données douanières volumineuses (1,8+ million de lignes, 2020–2026)
Produire des analyses statistiques et IA (détection de fraude, segmentation, prévision)
Exposer ces données via une API sécurisée avec gestion des rôles
Visualiser les résultats dans un dashboard web moderne multi-onglets

4. 📈 Analyses Statistiques Avancées
4.1 Corrélations (Spearman)
Variables	Corrélation	Interprétation
Poids Net ↔ Poids Brut	0,9965	Cohérence physique absolue
Valeur CFA ↔ Valeur FOB	0,9465	Cohérence financière validée
Quantité ↔ Valeur CFA	0,4086	Relation modérée (valeur unitaire variable)
4.2 Saisonnalité (Autocorrélation)
Lag 7 jours → 0,854 : Cycle hebdomadaire extrêmement fort
Lag 14 jours → 0,825 : Saisonnalité bi-hebdomadaire confirmée
Creux en août, pics en novembre–décembre
4.3 Concentration de Pareto
Les 20 % d'importateurs représentent 98,54 % de la valeur totale
Les 20 % de codes tarifaires concentrent 97,50 % du montant global
4.4 Tests Chi-Deux
Mode de transport ↔ Devise : P-Value = 0.000 → dépendance statistiquement significative

6. 🔐 Backend API — FastAPI (app.py)
6.1 Architecture de Sécurité
Authentification JWT (HS256, 24h d'expiration)
Hachage bcrypt des mots de passe
Contrôle d'accès par rôle (RBAC)
Logs d'audit SQLite (timestamp, IP client, IP serveur, localisation)
